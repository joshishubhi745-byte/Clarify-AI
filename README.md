# 🎓 Clarify AI

> An AI-powered learning platform that helps students understand concepts faster through intelligent tutoring, real-time assistance, and personalized learning support.

## 📖 Overview

Clarify AI is a modern educational web application designed to simplify learning through Artificial Intelligence. The platform acts as a virtual tutor, allowing users to ask questions, receive detailed explanations, and gain a deeper understanding of complex topics in an interactive and engaging way.

By integrating Google's Gemini AI, Clarify AI delivers accurate, context-aware responses that enhance the overall learning experience.

## 🚀 Getting Started

### Prerequisites

* Node.js
* npm (Node Package Manager)
* Google Gemini API Key

### Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/Clarify-AI.git
```

2. Navigate to the project directory

```bash
cd Clarify-AI
```

3. Install dependencies

```bash
npm install
```

4. Create a `.env` file in the root directory

```env
GEMINI_API_KEY=your_api_key_here
```

5. Start the server

```bash
npm start
```

6. Open the application in your browser

```text
http://localhost:3000
```
